# 每日两篇论文

每天北京时间 **08:30** 随既有练习任务提供两篇近期论文，主题为剪枝、量化、模型压缩与边缘端部署。优先近 180 天首发；按 arXiv ID / DOI 去重。详细规则见 [练习规范](../PRACTICE_SPEC.md)。

入口：[历史索引](../../paper/index.md) · [最近一期：2026-09-22](../../paper/2026-09-22/README.md) · [选题记录](../../paper/progress.json)。

每篇包括核心思想、证据与局限、复现难度及路线、简单代码和运行结果。分别标明作者报告、独立机制示例和完整复现；示例能运行不意味着整篇论文已复现。沿用既有定时任务读取规范的流程，不另外创建定时任务。

论文示例若涉及底层计算机体系结构、ARM 或 CPU 机制，必须使用 C/C++（默认 C++17），遵循总规范中的语言规则。

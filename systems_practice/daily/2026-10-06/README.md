# 2026-10-06 ARM SIMD / NEON：INT8块点积与scale边界

## 工业场景

机器人边缘模型的CPU小Batch点积：单行K=17/4099/65539，INT8×INT8，对称零点0、连续布局，默认group=32，每块独立FP32 scale，输出double。目标是缩短已量化数据的CPU计算阶段；不包含量化、排队、GPU/NPU、功耗或整模型推理。所有权由vector管理，读者不修改输入。长度不齐、非法scale、group超限必须拒绝。

源码先读：2026-10-06 [ggml仓库](https://github.com/ggml-org/ggml)，master的[arch/arm/quants.c](https://github.com/ggml-org/ggml/blob/master/src/ggml-cpu/arch/arm/quants.c)，`ggml_vec_dot_q8_0_q8_0`的NEON段和标量余块（1207–1245），及`quantize_row_q8_0`；MIT。原场景为分块量化张量内积，读取的实现每32项缩放再合并。这里是受启发的独立实现：保留块scale边界，增加任意尾部和显式范围检查；不兼容GGUF block结构，不复刻FP16 scale/SVE/i8mm/线程调度。使用FP32 scale及double合并隔离整数核差异。[来源记录](source.json)。

## 概念回顾

边缘推理的小批量量化点积常被看成把浮点乘法换成整数乘法，但真正的合同同时包含累加范围和缩放范围。本例输入是两条有符号八位向量，每个逻辑块分别携带浮点缩放系数。输出先在块内求整数点积，再乘该块的两个系数，最后按固定顺序合并。不同块的系数不同，所以不能为了减少乘法把缩放移到整条向量归约之后。用两块全一输入就能构造错误，不必依赖随机模型才能发现问题。

基础向量路径先把八位乘积扩到十六位，再把相邻乘积扩到三十二位累加。这里扩宽的时机比寄存器名称更重要：负一百二十八乘自身得到一万六千三百八十四，两个这样的乘积已经超过有符号十六位上界。只在循环结束时扩大类型无法修复此前的回绕。代码约束每块最多四千零九十六项，使块总和也在三十二位范围内；长向量通过逐块缩放进入双精度归约，不把无限长度整数和塞进一个寄存器。

点积扩展可以让一条指令把四对字节乘积累加到每个三十二位通道，但编译器允许生成指令不代表运行设备支持。程序把扩展函数与基础路径分开，并在调用前查询宿主能力，未知时回退扩宽实现。尾部只读取有效元素，不假设逻辑长度后面还有可读填充。标量、扩宽和点积版本共享输入、块边界、缩放顺序与输出检查；基准排除生成和校验，统计的是一百次调用的批均值。指令减少只是优化假设，小块调用、归约和缩放可能成为新的主要成本，必须用同条件测量决定是否采用。

## 知识图谱

| 连接 | 正确性条件 | 可观察证据 |
| --- | --- | --- |
| INT8乘积→SMULL→SADALP→INT32 | 不先在16位相加；group≤4096 | 极值输入、真实汇编 |
| 块整数和→块scale→double总和 | 缩放粒度跟数据块相同 | 手算672，对照错误64 |
| CPU能力→函数分派→SDOT | 编译target与运行时能力都成立 | runtime_dotprod=1、独立扩展函数 |
| vector所有权→有效长度→尾部标量 | 不越界读取，空输入返回0 | 0..513长度、ASan |

前置是有符号表示、NEON lane、乘法与加法的整数提升。INT8是格式，分块缩放是量化语义，SDOT是指令；三者不能互相替代。

## 正确性验证

通过4116个shape/极值案例、4类拒绝输入；8种group，0..513长度，4095/4096/4097与131072极值长输入。oracle逐元素乘相应scale，和块版独立组织。scale取二进制可精确表示数，结果检查相等；这不证明任意实际模型scale无舍入差异，生产应按模型设容差。group4096极值总和上界67108864；若试图整条K=131072以INT32归约，上界2147483648超过最大值，代码不执行该溢出路径。

## 性能分析

20预热，41样本，每样本100调用，steady_clock；计时含CPU内核调用、块归约和scale，不含validate、生成、分配。volatile结果阻止消除。顺序执行、频率/温度未固定，无PMU；P95是批均值分位数，不是请求尾延迟。逻辑每K项至少读2K字节加8ceil(K/group)字节scale；不等于DRAM流量。小块函数调用与逐块double加法可掩盖SDOT差异，不能从指令条数推算周期。

## 工程注意事项

允许零scale，拒绝负值/NaN/Inf。group限制是API合同；单独内部kernel只接受已经校验的块。输入不可与并发写者共享，vector RAII不等于线程安全。上线先检测设备/编译器、采集代表模型K与group、正确性回归，再加入自动向量化基线和持续热负载；若SDOT无收益保留扩宽路径。完整目标迁移步骤见ARM14。

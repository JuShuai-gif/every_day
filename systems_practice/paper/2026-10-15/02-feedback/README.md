# Revisiting Error Feedback：trace最优与有限格误差

## 论文与阅读范围

[arXiv:2610.18139v1](https://arxiv.org/abs/2610.18139v1)，Wai-Yiu Keung、Chi Cui、Wing-Kin Ma、Jesús Cid-Sueiro、Hei Victor Cheng，首发/v1为2026-10-13；2026-10-15读[全文](https://arxiv.org/html/2610.18139v1) §2–4.1、§5.1表2与§5.2表3选段。预印本，未核实同行评审接收。原文与检索未找到可确认的作者实现仓库；nanoGPT是引用的基础项目，不冒充本算法代码。来源与失败边界见[source.json](source.json)。

## 方法与有条件结论

因果量化按 `b_i=w_i+Σg_ij q_j`、`q_i=Q(b_i)-b_i`顺序产生误差，总误差为Gq。各瞬时误差独立等方差的假设下，设计目标是trace(GᵀHG)；联合旋转的下界为n·det(H)^(1/n)。有限格的范围/scale与饱和破坏固定噪声统计假设。作者MNIST表2，M=2时objective EFQ准确率降4.83个百分点，joint降44.34；更小代理值不保证任务收益。原文也区分Jacobian代理、真实logit误差与精度。[方法/有限格讨论](https://arxiv.org/html/2610.18139v1#S4)。

## 独立小例与结果

Python3.9+标准库，工作目录本课，`sh run.sh`。二维H=diag(4,1)，R=[[√(2/3),√(1/3)],[-√(1/3),√(2/3)]]，G下三角系数√2/2，使trace从5到4，恰好达到2√det(H)=4。量化格固定[-1,-0.5,0,0.5]，枚举1521个权重；先旋转、因果反馈量化、再逆旋转，用原H衡量实际误差。

[CPU实际输出](results/cpu.json)：755个改善、687个退化、79个相等，第二坐标反馈越范围357次。例如[-.95,-.95]误差从.0125增至.21016047；第二坐标未越界不意味着第一坐标未受旋转范围影响。本例未重新优化scale，正好隔离“固定trace结论不能保证固定有限格”的问题，不证明唯一退化原因。没有训练更新，属于PTQ机制例，不称QAT；没有真实低位文件或低位kernel性能。

[首版失败](results/initial-attempt.txt)保留：固定旋转二维反馈是条件最优，预设应出现退化的断言失败。修订改用联合旋转，不把失败偷偷删掉，也不归因作者实现。

## 复现难度与工程迁移

小例易，完整论文中到高：需要PyTorch、训练好的MLP或本地语言模型、Jacobian/校准统计、独立调参和测试集、模型推理设备；作者代码未确认，需从公式独立实现并逐级比对。最小路线先验证因果误差恒等式与SPD矩阵下界，再在小MLP对齐RTN/local/objective指标；模型级任务与GPU性能未做。不得用此标量循环冒充原生4bit Tensor Core吞吐。所有未来CUDA目标仍Thor sm_110，后端构建/性能未验。

故障链一：trace下降实际误差升→旋转扩大范围、饱和或噪声相关→同时记scale/端点/误差协方差，比较冻结格与重新校准→重新选scale/回滚旋转→独立测试验证，不能只优化代理。

故障链二：logit MSE更小准确率却差→决策边界与平均误差不同→记录任务指标和错误样本，不仅均方误差→按独立验证集选择→固定测试集一次评估。

验收：分离calibration/tuning/eval；SPD/damping记录；同位宽、同格或明确scale差异；输出PTQ/QAT与部署kernel状态；不虚构设备收益。

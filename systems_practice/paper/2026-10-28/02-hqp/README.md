# HQP：敏感度感知混合量化与剪枝

## 问题与核心思想
先以 Fisher 近似敏感度做结构剪枝，再在精度约束下做 INT8 PTQ；仅做独立顺序决策例。

## 一手阅读与复现边界
已阅读 arXiv 一手全文选段（方法、实验、局限）与标题/日期；没有把摘要或独立例冒充完整复现。作者仓库未核实；`example.py` 只表达选择/预算机制，省略模型、校准数据、训练、导出和设备 kernel。

## 结果与工程取舍
独立例运行通过，输出 `kept [2, 0] removed [1, 3]`。真实部署仍需比较模型精度、存储、CPU/GPU/NPU 设备时间与端到端延迟；没有 Thor 或完整模型数据，不能采用论文速度数字。

## 复现路线
固定论文版本与模型后，先重跑作者 calibration/eval，再把结构变更导出到 TensorRT/RKNN；所有 CUDA 扩展固定 `sm_110`，并分开记录 CPU、设备、E2E。

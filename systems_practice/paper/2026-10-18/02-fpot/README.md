# Fractional Power-of-Two Quantization：校准真实近似码本

Sunghyun Wee、Geunjae Choi、Hyeonjin Kim、Suyoung Kim、Nojun Kwak；[arXiv:2610.21257v1](https://arxiv.org/abs/2610.21257v1)，首次/本版本2026-10-15。[全文](https://arxiv.org/html/2610.21257v1)标注Accepted at NeurIPS 2026，这是论文自述，未独立核验会议名单；实际读§3、§5.2–5.4与§6局限。作者实现仓库未核实。

## 方法与有上下文的作者结果

半八度网格用`sign*s*2^(e/2)`，配均匀整数激活；奇数指数需要sqrt(2)因子，用1.5近似时应该按实际码本重新量化，而不是量化后偷偷替换。scale校准、非均匀格式、激活位宽与训练范式分别看；本方法不是把INT4改名FP4。

作者表2在Llama-3-8B W4A4KV4、单校准seed下，1-adder事后替换PPL7.729，按近似网格校准为7.574。作者§6说明硬件收益来自分析/综合，并未完成端到端ASIC验收；不能外推Thor加速。例子不采用论文网格选择/零阈值的全部细节，见下方简化。

## 独立示例、运行与实测

```sh
sh systems_practice/paper/2026-10-18/02-fpot/run.sh
```

Python3.9标准库；W64、X32×64用于校准搜索scale，独立X31×64评估，另做首通道4倍分布变化。PTQ没有训练更新，选scale不看评估。以线性最近距离选码（不是论文log round＋自适应零阈值），比较PoT、精确网格定码后换1.5、直接近似网格调参。真实nibble文件44B（12B头/scale＋32B码），读回后计算。

评估输出MSE实测54.17399 / 10.69458 / 11.96857；近似网格在本评估集反而略差，分布变化MSE分别73.55804 / 13.37324 / 13.17331。保留反例，不能以论文平均改善承诺每批提升。见[results/run.txt](results/run.txt)。

62组整数shift-dot与解码浮点dot对齐：奇数指数用3*x并在最终除2，保留1个小数guard bit。Python整数不限宽度，本例没有模拟有限硬件溢出。若直接`x+(x>>1)`，x=-3得到-5，不是-4.5；这是舍入语义差异，不能称为完全相同运算。输出文件与运算是独立教学实现，不是原作者kernel。

## 复现、故障诊断与限制

难度：小码本易，完整LLM/硬件难。需要作者代码版本、旋转预处理/GPTQ、模型/校准/评估数据；完整框架依赖尚未核实。先固定码本/零规则/舍入/累加位宽，再复现一层重建，最后任务评估与RTL/设备验证。没有训练、安装、模型下载或Thor运行，亦未计时Python循环冒充硬件吞吐。

故障一：离线误差小、运行误差大→执行码本近似但校准用精确sqrt(2)→逐码核对解码值→校准实际网格；实测无收益时回退。故障二：负激活偏差→右移截断/符号规则不一致→用-3等奇数输入核对→固定guard bit与最终舍入；扩大累加宽度增加成本，硬件节省不能只数乘法器。

迁移验收要有实际有符号范围/溢出测试、校准分区、导出元数据、端到端功耗与延迟；今日均未证明硬件收益。CUDA候选只能固定Thor SM110，其它设备仅作作者结果背景。

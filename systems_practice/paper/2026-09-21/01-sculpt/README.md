# SCULPT：让视觉模型提前适应 PTQ

论文：**SCULPT: Training Edge Vision Models for Post-Training Quantization Readiness**。Bharadwaj Kavuri 等；首次提交 **2026-09-01**，本次读 v1（距今 20 天）。arXiv 页面注明 IMVIP 2026，未另行核验会议记录。[元数据](https://arxiv.org/abs/2609.01743v1) · [全文](https://arxiv.org/html/2609.01743v1)。

## 主题思想与证据

问题是离群激活拉大量化范围。SCULPT 在 FP32 微调时改善激活分布，再做 PTQ：原激活函数之后增加分位数裁剪，边界用衰减动量更新后冻结；在 Conv/Linear 输出上增加偏度、峰度的单侧正则。训练过程不插入 fake quant，不能直接称为 QAT。关键关系为：

```text
A = activation(X)
alpha_t = alpha_0 / (1 + gamma*t)
M_t = (1-alpha_t)*M_(t-1) + alpha_t*quantile(A)
Y = clamp(A, M_lower, M_upper)
R = a*max(0, skew)^2 + b*max(0, kurtosis-3)^2
```

偏度项不是绝对值，也不是强制均匀分布。论文在 EfficientNet-B0 / ImageNette 的匹配 QDQ 设置下报告：W8A8 top-1 从普通 PTQ 的 **90.5478%** 到 **99.3631%**；但专门针对 W4A8 的 QAT 在其目标设置中优于 SCULPT。上述是作者结果，不能推广成所有模型或位宽的保证。已读方法 §3、设置 §4、结果 §5 / 表 1。[原文依据](https://arxiv.org/html/2609.01743v1#S3)。

## 复现难度与建议路线

**机制示例：易。完整实验：中到难。** 本次未找到可核实的官方实现，因此不能提供猜测的作者 API。难点在模块插入位置、训练状态冻结、PTQ 图边界和验证集选择，而不只是实现一个 clamp。

以下是本栏目的复现建议，不是已经执行的步骤：

1. 用已有 PyTorch 环境和一个小分类网络，先锁定数据划分与 FP32 基线；再分别加入裁剪、正则、两者组合做消融。
2. 训练只更新训练参数与范围；校准集确定量化参数，验证集选择 checkpoint，测试集只作最终评估。导出再加载后核对边界和预测一致性。
3. 再扩展到原文模型/数据并逐项对齐超参数与 QDQ 图；最终单独在目标设备核对算子支持、任务精度、延迟和内存。

小示例只需 Python 3.9+ 标准库、普通 CPU，几分钟即可阅读运行。完整复现需要深度学习环境、数据及训练设备；准备数据和调试预计数个工作日，属于工程估计，训练时间与显存未测。当前没有下载数据、训练网络或验证 Thor 部署。

**这个例子中裁剪使整体误差变大。** 它缩小量化步长、改善多数值，却损伤大离群值；没有训练让模型适应这种变化。应重点看为何要结合任务损失与分布训练，而不能把“去掉离群值”直接当作更高精度。这里的 MSE 是合成激活误差，不是分类准确率。

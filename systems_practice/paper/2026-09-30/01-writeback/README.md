# When Quantization Breaks Memory: Recurrent-State Write-Back in Low-Precision Temporal Inference

Ismail Erbas、Xavier Intes、Vikas Pandey；[arXiv:2609.04490v1](https://arxiv.org/abs/2609.04490v1)，首次及所读版本2026-09-03，预印本，CC BY-NC-SA4.0。2026-09-30实际读[全文](https://arxiv.org/html/2609.04490v1)§2.1–2.3、§3.1–3.2、S8公式S15–S19、S10存储口径、S11代码可用性；没有把摘要当全文。

## 问题与方法

循环状态q被下一步读取，量化改变后续轨迹。论文定义写入裕度`M=2*|h-q_old|/Δ`；内部格点M<1的更新不会改变存储值。误差反馈为`q=Q(h+e_old)`、`e=clip(h+e_old-q,-Δ,+Δ)`。残差是额外状态，不是训练参数。

作者固定一个GRU检查点、只改变回写，报告两个寿命估计误差约70倍和300倍恶化；限于其荧光寿命数据、检查点和对照，不能泛化到所有RNN或INT4模型。附加状态的存储相同也不代表计算/能耗相同。[方法与实验](https://arxiv.org/html/2609.04490v1#S2)。

## 独立现成实验与输出

本目录`sh run.sh`，Python3.9标准库。`example.py`独立构造60次+0.01的标量递推，四位对称网格Δ=1/7；它保留“下一次读取上次存储值”和有界误差反馈，省略GRU门、训练、数据生成、任务readout。参数更新0，不冒称QAT。

真实结果见[results/cpu.txt](results/cpu.txt)：无反馈最终0、目标0.6；反馈最终0.5714286、残差0.0285714，二者相加回到0.6。轨迹RMSE从0.3507373到0.0405280，仅为本构造输入数值。零增量、交替方向、端点饱和、half-step ties与nibble解码检查通过。

单状态示例实际用1B nibble容器+4B FP32残差=5B；理论每状态4+32=36bits仅在多个状态密集打包时有意义。并未复现论文的2bit方向记忆或低位残差方案。误差改善不意味着压缩总体存储变小，也无硬件性能结论。

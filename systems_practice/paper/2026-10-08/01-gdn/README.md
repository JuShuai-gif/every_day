# Why Gated DeltaNet Survives 4-Bit Quantization

完整标题：**Why Gated DeltaNet Survives 4-Bit Quantization: NVFP4 W4A4 for the Recurrent Half of a Hybrid 27B LLM**。作者Sergii Kozyrev、Davyd Maiboroda；[arXiv:2609.04098](https://arxiv.org/abs/2609.04098)，首次公开2026-09-03，本次2026-10-08读取v1。预印本，未核实同行评审发表。实际读[全文v1](https://arxiv.org/html/2609.04098v1)第2–4节、表1、第5.1–5.4节、第6节和第9节局限。

## 问题与两个机制

边缘服务的长上下文请求会反复更新递归状态，投影层4bit量化的误差可能进入后续全部token。本文研究混合模型中的Gated DeltaNet部分，而不是把所有中间状态都改成4bit。**投影W4A4**和**递归状态更新精度**是不同边界；NVFP4是浮点编码及分块scale格式，W4A4是位宽配置，PTQ是校准范式，不能混称同一算法。

机制一是delta更新的误差删除。采用列向量约定，状态满足

`S_t = alpha_t S_(t-1) + beta_t k_t (v_t - S_(t-1)^T k_t)^T`。

忽略新的量化扰动时，旧状态误差沿当前key方向被额外衰减，正交方向主要受alpha控制。归一化key、门值范围、覆盖到的方向以及持续注入的噪声都影响稳定性；不是“递归结构天然免疫量化”。例子用固定alpha=.999、beta=.2比较交替key与固定key；固定key永远不会主动纠正未被访问的正交误差。

机制二是部署融合的scale合同。若分支i的反量化为`W_i = g_i * b_i * q_i`，融合kernel只收一个global scale `g=max(g_i)`，则必须把每块scale改成`b'_i=b_i*g_i/g`。只拼q和旧b再换成公共g会改变函数。这个等价变换在实数下成立；真实NVFP4中block scale也有有限精度，重新编码、饱和以及下溢仍要量化验证。示例只验证实数代数，没有实现NVFP4编码器。

知识图谱：`投影量化扰动 → key方向误差消除/门控衰减 → 长序列状态`；`分支量化尺度 → 融合公共尺度 → block重编码 → 部署精度`。前者不能替代后者的数值等价检查。

## 作者结果与局限

作者表1报告Qwen3.8-27B混合模型（48个GDN、16个attention block，496个Linear使用W4A4），单卡RTX PRO 6000 Blackwell SM120、vLLM0.27.1、TP1条件下，任务平均分BF16为85.62、量化为85.10，显存50.13→17.53GiB，32K输入TTFT 6.90→4.03秒。**这些都是作者平台结果，本课没有复测，不是Thor数据。** 不跨硬件推算收益，也不把显存差全归因于某个kernel。

论文证据局限为一个模型/一种格式，PPL实验至32K、检索至64K；128K或其他递归架构仍需独立验证。门值异常、key子空间覆盖不足、持续偏置噪声以及融合scale错误均能破坏良好表现。

## 工业故障链与迁移验收

| 触发→信号 | 根因/诊断 | 修复与回归 |
| --- | --- | --- |
| 独立Linear精度好，融合部署突然失准 | 分支global scale不同；逐分支dump反量化值 | 统一global并重编码block scale，检查尾块与零块；不能只看校准loss |
| 短序列正常，长序列某方向持续偏差 | key覆盖不足或持续偏置噪声；按方向画状态误差 | 同时测固定/交替/相关key及长序列，保留状态高精度候选；不要仅改位宽标签 |

板端验收需固定输入序列、比较逐层误差、记录实际后端和回退、独立测kernel与TTFT；本课CPU代数通过不能关闭这些待办。

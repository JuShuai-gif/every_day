# DAMP: Decay-Aware Mixed-Precision Recurrent-State Quantization

Tao Zhang、Jianchao Tan、Pingwei Sun、Yanqi Yu、Zixu Jiang、Yuchen Xie、Xunliang Cai、Ziqian Zeng。[arXiv2608.27513v1](https://arxiv.org/abs/2608.27513v1)，首次/所读版本2026-08-27，36天内；[全文](https://arxiv.org/html/2608.27513v1)。预印本，未确认会议发表。实际阅读§1–7、公式6–10、表1、附录A.3–A.5/E/F；作者仓库搜索未找到可核验DAMP实现，全文没有作者实现链接，不把arXiv网页维护GitHub链接当代码。论文CC BY4.0，未复制代码。

## 问题、方法与作者结果

循环状态被反复量化写回，局部误差还受后续衰减影响。DAMP使用风险C=E/max(1−a_eff²,τ)，按固定预算保护高风险通道；GDN同head共享衰减，排序退化为量化误差排序。作者表1报告Qwen3.6-35B的AIME2026：FP32为85.46，9.9bit状态DAMP为83.65；是模型状态存储方案，不是所有权重都9.9bit。附录F指出该风险仅近似对角衰减，不描述完整时变转移；硬件/服务配置会影响收益。

## 复现难度与路线

难：公开论文可读，但作者完整校准、状态布局、融合执行器尚未核实。原文使用Qwen3.6-35B-A3B和Kimi-Linear-48B-A3B-Instruct、SGLang；实际所需checkpoint、框架patch、数据版本和设备组合必须先固定，不能只用通用SGLang冒充作者实现。不自动下载模型或安装依赖。

先取作者代码/许可证→小状态验证量化写回/通道置换→用独立校准统计构造固定layout→heldout轨迹→完整任务→Thor SM110实测。校准成本、算子和TPOT分开；论文其他GPU结果不可移植成Thor数字。本课没有GPU kernel，不提供虚构后端命令。

## 失效与工程迁移

故障一：a接近1时溢出或预算全部集中→核对分母、cap和有效轨迹长度→使用有界统计并heldout验证；不能由人为截断声称真实状态稳定。故障二：只保护误差最大的通道却长期误差高→同时比较注入幅值与衰减→在独立轨迹上验固定layout；若真实转移存在交叉耦合，标量代理可能失效。故障三：重排了状态却没重排query/key等操作数→单步输出立即偏移→先核对置换等价性，再测长轨迹，不把精度下降归咎于位宽。
